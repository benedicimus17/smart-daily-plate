# 🥗 Smart Daily Plate

> **Дзен-інтерфейс контролю харчування та балансу БЖВ нового покоління.**  
> Створено на базі React 18, TypeScript, Tailwind CSS, Zustand та PWA.

---

## 📱 Повна підтримка мобільних платформ

Застосунок оптимізовано за принципом **Mobile-First & Progressive Disclosure**:

### 🤖 Android (Смартфони та Планшети)
1. Відкрийте застосунок у **Google Chrome**.
2. Натисніть меню (три крапки) у правому верхньому кутку.
3. Оберіть **«Встановити додаток»** (або «Додати на головний екран»).
4. Додаток з'явиться на робочому столі як повноцінний нативний APK/PWA з підтримкою офлайн-роботи та жестів.

### 🍏 iOS (iPhone, iPad)
1. Відкрийте застосунок у **Safari**.
2. Натисніть кнопку **«Поділитися»** (квадрат зі стрілкою вгору).
3. Прокрутіть вниз і виберіть **«На початковий екран»** (Add to Home Screen).
4. Застосунок відкриватиметься на весь екран без адресного рядка з урахуванням **Dynamic Island**, чолки та Safe Area.

## 🍳 6 Кілер-фіч проєкту

1. 🍳 **Cook-Loss Engine**: точний розрахунок концентрації КБЖВ на 100 г готової страви з урахуванням ваги сухого посуду та випаровування води.
2. 📱 **1-Click Recipe Parser**: швидкий імпорт рецептів за посиланням з TikTok/Instagram Reels або текстом з розрахунком на 1 порцію.
3. 💡 **Macro-Gap Solver**: розумна підказка страви та грамів під вечірній дефіцит білка та калорій.
4. 🍽️ **Dining Out Estimator**: оцінка ресторанних страв без ваг методом візуальних долонь (Palm, Fist, Cupped hand, Thumb).
5. 🏦 **Weekly Flex Bank**: тижневий калорійний банк з динамічним перерозподілом без стресу та почуття провини від переїдання.
6. ⚖️ **True Fat Trend**: EMA-фільтр ваги ($\alpha = 0.1$) для відсікання 1-2 кг затримки солі та води.

## 🛠️ Запуск розробки

```bash
# Встановлення залежностей
npm install

# Запуск локального dev-сервера
npm run dev

# Запуск модульних тестів (Vitest)
npm test

# Збірка продакшн PWA
npm run build
```
