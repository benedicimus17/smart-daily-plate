# Статут проєкту: Smart Daily Plate

## Концепція продукту
Простий, інтуїтивний та естетичний застосунок для контролю харчування, розрахунку калорій, БЖВ та приготування страв на базі React + Tailwind CSS + PWA.

## Затверджений дизайн-референс
- **Стиль**: Frosted Glassmorphism, мінімалістична палітра (#F8F9FA, смарагдовий зелений, теплий бурштин, індиго), круглі плаваючі картки.
- **Мокап**: `smart_daily_plate_ui_showcase.jpg`

## 6 Ключових кілер-фіч
1. **Cook-Loss Engine**: розрахунок каструлі/сковорідки (сире ⟷ готове з урахуванням випаровування води).
2. **TikTok / Reels / Web Parser**: імпорт рецептів в 1 клік з розрахунком макросів на порцію.
3. **Macro-Gap Solver**: розумна підказка «Що доїсти під залишок ккал/білка?».
4. **Dining Out Estimator**: оцінка ресторанних страв без кухонних ваг.
5. **Weekly Flex Bank**: тижневий калорійний банк замість щоденного стресу від переїдання.
6. **True Fat Trend**: EMA-фільтр затримки води й натрію.
